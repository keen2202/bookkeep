## 状态维护规则
1. 任一时刻至少一个任务为 `in_progress`；完成当前任务后按 DAG 顺序解锁下一个（当前在制品：BK-R-001）。
2. 任务被外部因素卡住时标记 `blocked` 并记录原因，同时从可用任务中启动另一个保证在制品 ≥ 1。
3. 每次状态变更同步更新：本文件、《06-审查修复Spec规格说明.md》§4 进度追踪表、任务管理工具条目。
4. 粒度控制：修复类任务 0.5~3 天；超出则拆分，低于则合并。
5. 波次出口标准：MR-1（第一波）= 原 P0 宣称全部真实闭环；MR-2 = 数据安全达标；MR-3 = 商店级体验与体积；MR-4 = v1.0 质量门禁，完成后回填《04-验收报告.md》审计记录。
