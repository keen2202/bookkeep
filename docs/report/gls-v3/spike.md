## 1. L0–L4 同屏样张

样板间 `component_gallery_page` 新增「玻璃层级 L1–L4」展区：四层同屏 + 实时参数
标注（σ / fill α% / border α%）。层级三参数单调性由
`test/unit/shared/theme/glass_layers_test.dart` 锁定：

- σ：10 → 16 → 28 → 36（规范表严格递增；standard/saver 档按 §2.3 归零规则）；
- 填充 α（浅）：0.55 → 0.65 → 0.75 → 0.85；
- 填充 α（深）：0.66 → 0.72 → 0.80 → 0.86；
- 描边 α：浅 0.20/0.22/0.25/0.30；深 0.16/0.18/0.20/0.24。

**判定：通过（单元测试锁定），参数表冻结。**

## 2. 顶部高光 A/B（渐变 vs solidLine 双细线）

- 默认启用渐变高光（`kGlassHighlightStyle = gradient`），stop 区间
  [0, 45%] 高度、间隔充足；
- solidLine 分支已在 `resolveGlassSpec(highlightStyleOverride:)` 单点实现，
  样板间「色带探针」展区提供 A/B 一键切换；
- 单元测试锁定分支行为：solidLine 下 `topHighlight == null` 且 α_top 保留。

**判定：默认 gradient 冻结；solidLine 作为单点降级开关保留。**

## 3. 黑底色带探针

桌面端 Impeller 渲染下放大高光条未见可见台阶纹（样板间展区人工目检，
开发侧）。**真机中端机复核列为遗留清单 R-1。**

## 4. 深色描边 α ∈ {0.12, 0.16, 0.18} 可见度对比（对照 Spec §2.4 手算）

以 T5 石墨·夜 standard 档 L1 为 worst case，程序化复算与手算一致：

| 方案 | 合成描边色 | 对比度 | 判定 |
| --- | --- | --- | --- |
| ×0.6（α=0.12） | #34373C ≈ | 1.44:1 | **否决**（< 1.5 下限） |
| **α=0.16（采用）** | #3D4045 | **1.64:1** | ✓ |
| α=0.18（上调备选） | 更亮 | > 1.64:1 | 备用 |

测试锁定：T5–T8 四套深色预设 × 四层级全部 ≥ 1.5:1。
浅色基底按 Spec §2.4 说明属预期弱增量（白玻璃上白线数学上不可达 1.5:1），
轮廓定义由阴影 + 顶部高光 + 光斑边缘色差承担——1.5:1 锁定范围收敛为深色
基底（glass_layers_test 注释注明依据）。

**判定：深色描边实值表 0.16–0.24 冻结；L1 上调 0.18 备案不启用。**

## 5. 标准档 L1 观感（三段软化 blob + 补偿 alpha）

standard 档软化曲线 `[0.95I@0, 0.45I@0.55, 0@1]` + 浅 L1 补偿 0.06 /
深 L1 补偿 0.04 落地于 `AmbientGradient` 分档绘制。桌面渲染观感：光斑
边缘无硬边，fill-only 卡片有可感知的「隔一层轻磨砂」效果。

**判定：磨砂感可接受，无需触发第 5 光斑后备方案。真机复核列 R-2。**

## 6. ContrastGuard 系数 0.85 校准

48 组合矩阵（8 预设种子 × {soft, standard, rich} × 浅深两态）全部达标：
所有组合的有效强度均未被钳制（extraFillAlpha 恒 0），说明当前预设的光斑
alpha 上限在 0.85 残余透过率假设下留有充分余量。

**判定：系数 0.85 冻结；徽标逻辑保留（未来加预设/强度档先过此门）。**

## 7. 实施期发现的规范冲突与决议

| # | 冲突 | 决议 |
| --- | --- | --- |
| C-1 | Spec §4.7 背景相对亮度区间 (0.01, 0.99) 与自身冻结值矛盾：T5 提亮值 #13171C 的 WCAG 相对亮度实测 0.0084 < 0.01 | 按 Spec §2.4「表格值为规范源」原则，**冻结值优先**；测试执行界放宽为 (0.005, 0.995) 并逐值锁定冻结色；custom 派生路径仍严格执行 (0.01, 0.99) 钳制（`clampBackgroundLuminance` 二分插值兜底） |
| C-2 | Spec §3.2 `BackdropFilter(clipBehavior: Clip.hardEdge)` 在 Flutter 3.44 widget API 中不存在（render 层才有 clipBehavior） | 等价改用 `ImageFilterConfig.blur(bounded: true)`——SDK 文档明确其语义即「只从对象边界矩形内采样、杜绝相邻内容渗色」，配合外层 ClipRRect 保持双保险结构；widget 测试断言节点层级不变 |
| C-3 | AC-02 描边 1.5:1 若按字面覆盖浅色主题则数学上无解 | 收敛为「深色基底全层级 ≥ 1.5:1」+ 浅色基底「> 1.0 方向性可辨」，依据即 §2.4 自身对浅色的豁免说明 |
