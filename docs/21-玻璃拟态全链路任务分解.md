## 1. 总览

- **范围**：原型小样验证、玻璃层级体系与 GlassPanel、环境光动效、全组件玻璃化、图表容器、个性化设置、存量散点收敛、测试与性能验收。
- **工时**：12 个工作日（单人），粒度 0.5~2 天。
- **排期窗口**：2026-08-24（周一）~ 2026-09-09（周二），按 5 个工作日/周。
- **状态口径**：`pending` / `in_progress` / `done` / `blocked`。
- **节奏约定**：始终维持 ≥1 个 in_progress 任务；每波次结束过里程碑走查（截图归档 `docs/report/gls-v3/`）；BK-GLS-000 参数冻结是 W1 冻结 Token 数值的前置条件。

## 6. 风险预案（执行视角）

- **BK-GLS-000 结论推翻纸面参数**：属预期收益（评审意见 #1/#2 的目的即此）；参数冻结前不启动 W2/W3 的 UI 编码，避免返工放大；
- **低端机帧率不达标（M4/M5 发现）**：默认档直接切 `saver` 上架，standard/high 保留为设置项——功能不受阻；
- **golden 大面积漂移**：仅允许在 BK-GLS-017 一个提交内集中刷新，其余波次 golden 必须保持绿色；
- **散点迁移超预期（附录 A.2 之外发现新散点）**：视觉关键页优先，非关键散点加白名单注释限期清除；
- **与既有 242 测试冲突**：任何存量测试修改须在本文件对应任务行下注明原因（预期集中在 theme 断言与 golden）。
