## 0. 结论摘要

实现与三份文档的符合度**总体很高**：Token 层、8 套主题全量色值、语义色锁定、智能遮罩算法、组件库规格、持久化与兼容规则、Golden 基线、CI 卡点均**逐项核对一致**。

但发现 **1 个 P0 功能缺陷、2 个 P1 问题、4 个 P2 偏差**，以及 2 处文档状态与事实不一致：

1. **P0：外观页首次选图无 UI 入口**——`imagePath == null` 时开关禁用且"更换图片"按钮不渲染，新用户无法通过界面完成首次选图（死锁）；widget 测试绕过 UI 直调 controller 所以全绿，**集成测试步骤②在全新设备上必然失败**。
2. **P1：背景图渲染使用相对路径**，写盘用绝对路径，移动端 `Directory.current` 不可靠，真机上背景图可能静默不显示（被 errorBuilder 吞掉）。
3. **P1：Spec §9 要求的"旧键兼容迁移"单测缺失**，13 验收报告声称已覆盖，与实际不符。
4. P2：按钮收敛不完全（5 个文件残留 FilledButton/OutlinedButton）；lint 正则存在绕过缺口且范围仅 features/（设计文档要求"全项目"）；备份范围带入 `bg_*` 键；秒开入口未包 AppBackground。
5. BK-UI-017/018 在 11 文档标 done，但真机集成测试与性能指标均未执行，应为"部分完成（待真机）"。
