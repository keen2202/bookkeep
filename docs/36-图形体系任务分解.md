**总原则**

- 数值与语义只允许来自 34/35；玻璃容器 G1–G5 仍以 BK-DOC-23 为准。

- 每完成任务须更新本表 Status，并满足 Checklist 与关联 AC。
- **复杂度**：`S` ≤0.5 人日 · `M` 1–2 人日 · `L` 3–5 人日 · `XL` >5 人日。

**图例**

- **blockedBy**：前置任务 ID  
- **blocks**：完成后解锁的任务 ID
