## 1. Token 命名规范

所有 Token 集中在 `app/lib/shared/theme/glass_tokens.dart`（新建），命名规则：

```
glass.<类别>.<层级或语义>[.<模式>]
```

- 类别：`blur` / `fill` / `border` / `highlight` / `shadow` / `radius` / `glow`；
- 层级：`g1`–`g5`；语义：`bg` / `zebra` / `selection` / `button` 等；
- 模式缺省时提供 `light` / `dark` 双值，由 `ThemePalette.brightness` 分流；
- 组件代码**只允许引用层级**（如 `GlassLevel.g2`），禁止写字面量。

## 2. 基础 Token

### 2.1 主题色（Primary）

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `color.primary` | `#0A84FF`（iOS systemBlue） | `#409CFF`（提亮版） | 主按钮着色、选中光晕、聚焦环、图标 tint |
| `color.onPrimary` | `#FFFFFF` | `#FFFFFF` | 着色玻璃上的文字 |
| `color.danger` | `#FF3B30` | `#FF453A` | 删除等破坏性操作 |
| `color.success` | `#34C759` | `#30D158` | 收入 / 正向状态 |

> 主题色仅出现三处：主操作按钮、选中态（光晕 + 叠加层 + 描边）、图标 tint。除此之外全界面无彩色。

### 2.2 背景 Token（硬约束）

| Token | 浅色 | 深色 |
| --- | --- | --- |
| `glass.bg.base` | `#F2F2F7` | `#000000` |
| `glass.bg.gradientDelta` | 明度差 ≤ 3%，同 H 同 S 的垂直微渐变 | 同左 |

禁止：光斑、彩色渐变、Mesh、噪点、网格、背景图。实现上 `AppBackground` 只渲染 `base` 或 `base + 单色微渐变`，删除旧 `ambient` Mesh 全部代码与 Token。

### 2.3 遮罩 Token

| Token | 取值 | 用途 |
| --- | --- | --- |
| `glass.scrim` | `#000000` α 0.32 | G4 模态浮层背后的全屏遮罩 |

## 3. 玻璃层级参数表（G1–G5，核心规范）

填充基色统一为 `#FFFFFF`，通过 alpha 区分层级与模式。

| 参数 | G1 图标容器 | G2 内容面板 | G3 吸附层 | G4 浮层 | G5 轻提示 |
| --- | --- | --- | --- | --- | --- |
| `blur`（σ, px） | **12** | **20** | **28** | **36** | **44** |
| `fill` α（浅色） | **0.55** | **0.60** | **0.72** | **0.80** | **0.85** |
| `fill` α（深色） | **0.10** | **0.12** | **0.18** | **0.24** | **0.30** |
| 外侧描边（0.5px, #000000 α）浅色 | 0.06 | 0.06 | 0.08 | 0.10 | 0.10 |
| 外侧描边（0.5px, #000000 α）深色 | 0.30 | 0.30 | 0.35 | 0.40 | 0.40 |
| 内侧高光（0.5px, #FFFFFF α）浅色 | 0.35 | 0.35 | 0.40 | 0.45 | 0.50 |
| 内侧高光（0.5px, #FFFFFF α）深色 | 0.12 | 0.12 | 0.14 | 0.16 | 0.18 |
| 顶部内高光渐变（#FFFFFF α，浅/深） | 0.20→0 / 0.08→0 | 同左 | 同左 | 同左 | 同左 |
| 内高光覆盖高度 | 组件高度的 40%，自上而下线性和到 0 | — | — | — | — |
| 环境投影（#000000） | 0/2/8/α0.04 | 0/4/16/α0.06 | 0/6/20/α0.08 | 0/12/32/α0.12 | 0/8/24/α0.10 |
| 圆角 | 边长×0.28 | 16 | 通栏 0 / 浮条 16 | 20 | 14 / 胶囊全圆角 |
| 适用组件 | 图标底座 | 卡片、面板、按钮、表格容器、输入框 | AppBar、底部导航、表格表头 | 对话框、底部弹层、下拉菜单、日期选择器 | Toast、Tooltip、FAB |

> 投影格式：x/y/blur/alpha，spread 恒为 0。深色模式投影 alpha 与浅色相同（纯黑背景上投影天然弱化，无需加倍）。

**派生规则**：
- 层级参数单调性：blur 与 fill α 沿 G1→G5 严格递增，任何组件不得跨档取值；
- 卡片嵌套最多一层，内层升一档（如 G2 卡片内的分组容器用 G3 填充值但 blur 保持 20，不叠加第二个 BackdropFilter）。

## 4. 组件规格

### 4.1 FG-ICON 图标容器

| 规格项 | 取值 |
| --- | --- |
| 尺寸档位 | 28 / 36 / 44（正方形） |
| 圆角 | 尺寸 × 0.28（7.84 / 10.08 / 12.32，连续圆角近似） |
| 材质 | G1 全部参数（σ12，fill 0.55/0.10，双层描边，顶部内高光） |
| 图标本体 | 1.5px 等宽线、圆角线帽/线 join、尺寸 = 容器 × 0.55（15.4 / 19.8 / 24.2） |
| 图标颜色 | 默认 `text.primary`；可选 `color.primary` tint |
| tint 变体 | 容器 fill 混入主题色：浅色 `#0A84FF` α0.10 叠加 / 深色 `#409CFF` α0.08 叠加 |
| 豁免 | 表格单元格内的文字型符号（如 ¥）不设容器 |

### 4.2 FG-SEL 选中态（毛玻璃高亮，四层叠加）

选中态为覆盖于宿主组件之上的组合效果，宿主组件原 blur 不变：

| 层 | 参数（浅色） | 参数（深色） |
| --- | --- | --- |
| ① 玻璃增亮 | fill α 提升至 **0.72**（G3 档） | fill α 提升至 **0.18**（G3 档） |
| ② 柔和光晕 | `color.primary` α **0.25**，blur **20**，spread 0，offset 0/0 | 同左（用深色提亮色 `#409CFF`） |
| ③ 透明叠加层 | `color.primary` 垂直渐变 α **0.12 → 0.06**（顶→底） | α **0.10 → 0.05** |
| ④ 描边 | 内侧高光 0.5px #FFFFFF α **0.50**；外缘 0.5px `color.primary` α **0.30** | 内侧 #FFFFFF α **0.20**；外缘 `#409CFF` α **0.35** |

- 过渡：200ms `cubic-bezier(0.4, 0.0, 0.2, 1)`，四层同步淡入淡出；
- 未选中态四层全部不存在（不是 alpha 0 常驻）；
- 禁止实色填充、禁止左侧色条、禁止仅文字变色作为唯一选中信号。

### 4.3 FG-TBL 表格

| 部位 | 参数 |
| --- | --- |
| 容器 | G2 全参数（σ20，fill 0.60/0.12，R16，双层描边，环境投影 0/4/16/α0.06） |
| 表头 | G3 档填充与模糊（σ28，fill 0.72/0.18）；底部 0.5px 分隔线：浅色 #000 α0.06 / 深色 #FFF α0.08；文字用 `text.secondary` 加粗 600 |
| 奇数行 | fill #FFFFFF α **0.45**（浅）/ **0.10**（深）；**禁套 BackdropFilter** |
| 偶数行 | fill #FFFFFF α **0.30**（浅）/ **0.06**（深）；斑马纹 alpha 差固定 0.15 / 0.04 |
| 行 hover | 该行 fill α +0.10（浅）/ +0.04（深），150ms 过渡 |
| 行选中 | 套 FG-SEL 四层全量 |
| 行分隔线 | 0.5px，浅色 #000 α0.05 / 深色 #FFF α0.06，左右内缩 16px |

### 4.4 FG-BTN 按钮（状态参数矩阵）

次级玻璃按钮（默认形态，G2 基材），浅色（深色）：

| 状态 | blur σ | fill α | 描边/高光 | 其他 |
| --- | --- | --- | --- | --- |
| 默认 | 20 | 0.60（0.12） | G2 标准双层描边 | — |
| Hover | **24** | **0.68（0.16）** | 内高光 α +0.05 | 150ms 过渡 |
| Pressed | **16** | **0.48（0.09）** | 不变 | scale 0.98；内阴影 inset 0/1/3 #000 α0.08 |
| Focus | 20 | 0.60（0.12） | + 2px 外环 `color.primary` α0.50 | 键盘导航可见 |
| 禁用 | **8** | **0.32（0.06）** | 去内高光、去光晕 | 文字 `text.disabled`，禁交互 |

主操作按钮（着色玻璃）：blur σ20 不变；fill = `color.primary` α **0.75**（浅）/ **0.65**（深）；文字 `#FFFFFF`；hover/pressed 仅变 fill α（+0.08 / −0.10）与 scale；禁用态 fill α 0.30、文字 α0.50。

通用规格：高度 44（标准）/ 32（紧凑）；圆角 12（标准按钮）/ 全圆角（胶囊按钮）；水平 padding 20；文字 15px/600。

## 5. 文字规格

| Token | 浅色 | 深色 | 字号/字重用途 |
| --- | --- | --- | --- |
| `text.primary` | `#1C1C1E` α1.00 | `#FFFFFF` α1.00 | 正文 15/400、标题 17/600、大标题 28/700、金额 20/600（等宽数字） |
| `text.secondary` | `#3C3C43` α0.60 | `#FFFFFF` α0.60 | 辅助说明 13/400、表头 13/600 |
| `text.tertiary` | `#3C3C43` α0.36 | `#FFFFFF` α0.36 | 占位符、时间戳 12/400 |
| `text.disabled` | `#3C3C43` α0.24 | `#FFFFFF` α0.24 | 禁用态 |

规则：文字实色渲染于玻璃之上，不随玻璃半透明；金额等数字用等宽数字字形；对比度全量 ≥ 4.5:1（≥18px 或 14px 粗体 ≥ 3:1）。

## 6. 动效规格

| 场景 | 时长 | 曲线 | 可动属性 |
| --- | --- | --- | --- |
| 微交互（hover/pressed） | 150ms | `cubic-bezier(0.4, 0.0, 0.2, 1)` | fill α、blur σ、scale（0.98–1.0） |
| 状态切换（选中/聚焦/主题切换） | 200ms | 同上 | FG-SEL 四层 alpha、全 Token 颜色 |
| 浮层进出 | 250ms | 同上 | 位移 ≤ 屏高 8% + 透明度 |
| 减弱动态效果 | 100ms | linear | 仅透明度 |

禁止：循环动画（呼吸/脉冲）、颜色无过渡跳变、blur σ 的逐帧高频动画（仅允许在离散状态间过渡）。

## 7. 双模式对照与对比度验算

### 7.1 合成底色（fill 白玻璃 × 背景）与主文字对比度

浅色模式（背景 `#F2F2F7`，文字 `#1C1C1E`）：

| 层级 | fill α | 合成底色（约） | 主文字对比度 | 次级文字对比度 |
| --- | --- | --- | --- | --- |
| G1 | 0.55 | `#FAFAFC` | 15.9:1 | 6.2:1 |
| G2 | 0.60 | `#FAFAFC` | 15.9:1 | 6.2:1 |
| G3 | 0.72 | `#FCFCFD` | 16.3:1 | 6.4:1 |
| G4 | 0.80 | `#FCFCFD` | 16.4:1 | 6.5:1 |
| G5 | 0.85 | `#FDFDFE` | 16.5:1 | 6.5:1 |

深色模式（背景 `#000000`，文字 `#FFFFFF`）：

| 层级 | fill α | 合成底色（约） | 主文字对比度 | 次级文字对比度 |
| --- | --- | --- | --- | --- |
| G1 | 0.10 | `#1A1A1A` | 15.4:1 | 6.9:1 |
| G2 | 0.12 | `#1F1F1F` | 14.3:1 | 6.5:1 |
| G3 | 0.18 | `#2E2E2E` | 11.9:1 | 5.6:1 |
| G4 | 0.24 | `#3D3D3D` | 10.1:1 | 4.9:1 |
| G5 | 0.30 | `#4D4D4D` | 8.6:1 | 4.2:1 |

全部 ≥ WCAG AA（4.5:1）；三级文字（α0.36）仅允许用于非关键信息，关键操作与数据禁止使用。

### 7.2 双模式取值总表

所有双值 Token 已在 §2/§3/§4 以「浅色（深色）」双列给出，代码侧由 `ThemePalette.brightness` 单点分流，禁止组件内出现 `isDark ? a : b` 散写。

## 9. 验收标准（Acceptance Criteria）

| ID | 标准 | 验证方式 |
| --- | --- | --- |
| AC-01 | 全代码库 `BackdropFilter` 的 σ ∈ {12, 20, 28, 36, 44}；fill/border/shadow 数值全部来自 Token 引用，无散写字面量 | 静态扫描脚本（P4-040） |
| AC-02 | 背景层无 RadialGradient / 多色 Mesh / 光斑 / 背景图；`ambient` Token 零残留 | 扫描 + 全页面截图核验 |
| AC-03 | §7.1 全部组合对比度 ≥ 4.5:1（大文字 3:1） | 自动化验算脚本，随 CI 运行 |
| AC-04 | 深/浅两模式全部页面截图走查通过，层次可辨、内容清晰 | 双模式截图基线比对 |
| AC-05 | 图标容器、选中态、表格、按钮、卡片、导航、浮层 100% 使用 §4 规格，无私有实现 | 组件走查清单 |
| AC-06 | 同屏 `BackdropFilter` ≤ 20；表格行/列表项零 BackdropFilter；目标设备滚动 ≥ 55fps | 性能面板采样 |
| AC-07 | 全应用无实色填充选中态，选中均呈现 FG-SEL 四层效果 | 截图走查 |
| AC-08 | 旧玻璃 Token 与组件（§8 清单）全部移除，编译无残留引用 | 编译 + 扫描 |
