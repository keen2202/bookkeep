## 3. 关键设计说明与偏差

| 项 | 说明 |
| --- | --- |
| 背景压缩格式 | Spec §5.4 要求"JPEG Q85"，但 dart:ui 仅支持 PNG 编码且 Spec D6 禁止第三方图像库——以**最长边 1920px + PNG 无损重编码**实现，分辨率与解码成本目标达成（见 `background_service.dart` 注释） |
| 状态栏明暗 | 原 AppBarTheme 静态 systemOverlayStyle 移入 AppBackground 动态计算（遮罩后有效亮度 > 0.5 → 深色图标，Spec §5.3），避免静态值覆盖动态结果；无背景时按主题明暗，行为不变 |
| 日历 Tab Golden | 含"今日"高亮、基线随日期漂移，不进 Golden（设计文档 §6.1 观感截图改人工走查） |
| 遮罩对比度评级 | 手动模式给出实时评级（优 ≥4.5 / 良 ≥3.0 / 差 <3.0，Spec §5.3）；次级文案对比度按"不透明卡片 surface"校验（数据区绝对可读，设计 §5.4.1），不压在遮罩底色上 |
