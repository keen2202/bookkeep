## 1. 设计背景与目标

### 1.1 为什么推倒重来

前序玻璃拟态方案（v2/v3）以「环境光 Mesh + 漂移光斑」为氛围来源，玻璃只是覆盖在彩色光斑之上的滤镜。这与 iOS 系统的毛玻璃语言存在根本差异：

- iOS 的毛玻璃是**材质本身**，不依赖背景里的彩色光斑来「显形」；
- iOS 背景保持**纯净**（系统浅灰 / 纯黑），层次完全由玻璃的模糊、透明度与描边构建；
- v3 方案参数分散（alpha 在多个调用点漂移）、组件玻璃化未闭环、背景光斑与「纯净简洁」诉求冲突。

因此本系统**从零重建**：只保留「玻璃是分层材质」这一抽象概念，全部参数、组件规格、Token 命名重新定义。

### 1.2 设计目标

1. **iOS 高度一致**：整体观感对齐 iOS 系统（通知中心、控制中心、通讯录列表的材质语言），半透明 + 背景模糊为核心；
2. **纯净背景**：背景严禁光斑、彩色渐变、网格、噪点，只允许纯色或极弱单色渐变（见 §3）；
3. **参数全系统统一**：模糊半径、透明度、边框、阴影全部收敛到唯一 Token 源（Spec §2/§3），任何组件不得私自取值；
4. **深浅双模式对等**：同一套层级体系在浅色与深色背景下均保证前景内容清晰可读（WCAG AA）；
5. **全组件闭环**：图标、选中态、表格、按钮、卡片、导航、浮层全部纳入毛玻璃语言。

### 1.3 非目标

- 不改动数据层、同步协议、业务逻辑（纯视觉层重构）；
- 不引入第三方 UI 库，玻璃容器自研（基于 Flutter `BackdropFilter`）；
- 不支持用户自定义背景图（纯净背景约束下，背景图会破坏可读性兜底，见 §3.3）；
- 不做 3D 视差、材质折射模拟等炫技效果。

## 2. 设计原则

| 原则 | 含义 | 落地约束 |
| --- | --- | --- |
| **纯净即高级** | 背景是画布，不是装饰。层次交给玻璃，背景保持绝对干净 | §3 背景白名单制：仅 2 个系统底色，禁一切装饰元素 |
| **模糊即层级** | 离用户越近的层，模糊越强、填充越实、描边越亮。层级差异必须同时体现在 ≥2 个维度 | §4 五层模型，每层参数三维度单调递增 |
| **单源参数** | 全系统只有一个参数源，组件只引用层级，不持有数值 | Spec §2 Token 表 + AC-01 静态扫描门禁 |
| **内容永不下沉** | 文字、图标、数字永远实色渲染在玻璃之上，不参与半透明 | §6 文字规格，AC-03 对比度验算 |
| **双模式对等** | 深色不是浅色的反色，而是同体系的另一套取值 | Spec §7 对照表，AC-04 双模式走查 |
| **克制动效** | 动效只表达状态变化，不表达个性 | §8，150–200ms，仅透明度/模糊/缩放 |

## 3. 背景系统（硬性约束）

### 3.1 背景白名单

全应用背景**只允许**以下两种取值：

| 模式 | 色值 | 说明 |
| --- | --- | --- |
| 浅色 | `#F2F2F7` | 等同 iOS `systemGray6`，系统浅灰 |
| 深色 | `#000000` | 等同 iOS 深色模式纯黑 |

允许的唯一变化：**同色系的垂直单色微渐变**（顶部到底部明度差 ≤ 3%，同 Hue 同 Saturation），用于避免大面积纯色的「死板感」。除此之外：

- ❌ 禁止光斑（任何形式的光斑 / 光晕 / 辉光装饰层）；
- ❌ 禁止彩色渐变、Mesh 渐变、多色混合背景；
- ❌ 禁止网格、点阵、噪点纹理；
- ❌ 禁止背景图片（含用户自定义上传）。

### 3.2 为什么禁止光斑

光斑的本质是「在背景里藏彩色色块，让玻璃透出颜色」。它带来三个问题：与 iOS 纯净语言冲突；不同页面光斑位置漂移导致视觉噪音；玻璃下的对比度随光斑位置不可控。本系统中，**玻璃的颜色来自填充本身，不来自透出的背景**。

### 3.3 可读性兜底

纯净背景是对比度可控的前提：背景色固定为 `#F2F2F7` / `#000000` 后，每一层玻璃的合成底色可以精确计算（Spec §7 给出全部层级的合成色与文字对比度验算值），从机制上保证任何文字落点都满足 WCAG AA。

## 4. 毛玻璃层级体系（G1–G5）

### 4.1 五层深度模型

```
G5  轻提示层    Toast / Tooltip / FAB                  最磨砂、最亮
G4  浮层        对话框 / 底部弹层 / 下拉菜单 / 选择器
G3  吸附层      吸顶 AppBar / 底部导航栏 / 表格表头
G2  内容面板层  数据卡片 / 列表面板 / 图表容器 / 图标容器所在的卡片
G1  图标容器层  图标的毛玻璃底座
─────────────────────────────────────────────────────────
G0  背景层      纯净底色（§3），非玻璃
```

深度语义：**离用户越近 → 模糊半径越大、填充越实（alpha 越高）、描边高光越强、投影越深**。层级差异必须同时在模糊、透明度、描边三个维度上单调变化，禁止单维度分层。

### 4.2 层级直觉

- **G1 图标容器**是最小单元的玻璃：给线性图标一个「嵌在玻璃里」的底座，统一全应用图标的视觉重量；
- **G2 卡片**是内容的基本容器，磨砂适中，既能托住内容又不喧宾夺主；
- **G3 吸附层**跟随内容滚动时压在列表上方，需要更强的模糊把下方滚动的内容「柔化」掉（对齐 iOS 导航栏行为）；
- **G4 浮层**是模态的，最接近用户，填充最实，保证弹层内容在任何背景下可读；
- **G5 提示**转瞬即逝，用最强的玻璃确保一瞥可读。

### 4.3 真模糊的使用边界（性能决策）

`BackdropFilter` 是真模糊，开销大。规则：

- **容器级组件用真模糊**：卡片、导航栏、浮层、Toast、图标容器；
- **重复渲染的行级元素禁用真模糊**：表格行、列表项的斑马纹只用填充透明度区分，不套 `BackdropFilter`（行的透明感来自其所在的 G2 容器整体模糊）；
- 同屏 `BackdropFilter` 实例 ≤ 20 个（Spec AC-06）。

## 5. 组件视觉语言

> 本节描述设计意图与视觉规则；**所有数值以 Spec 文档 §3/§4 为唯一准绳**。

### 5.1 图标系统

- **容器**：所有功能性图标必须置于 G1 毛玻璃容器中（仅表格内嵌文字型符号可豁免）。容器为正方形 + iOS 连续圆角（圆角 = 边长 × 0.28，近似 squircle），具备统一的背景模糊、半透明填充与微妙描边；
- **描边**：双层发丝线——外侧 0.5px 深色细线（勾勒轮廓）+ 内侧 0.5px 白色高光（模拟玻璃边缘折射）；
- **内高光**：容器顶部 40% 高度叠加白色透明渐变（上亮下消），模拟顶光折射，全系统参数统一；
- **图标本体**：简洁线条风格，1.5px 等宽描边，圆角线帽，SF Symbols 风格；实色绘制，不透明；默认可读文字色，可选主题色 tint；
- **尺寸**：28 / 36 / 44 三档，对应辅助图标 / 列表图标 / 主要功能图标。

### 5.2 选中状态（弃用实色填充）

选中 = **毛玻璃高亮**，由四层叠加构成，禁止任何形式的传统实色块填充：

1. **玻璃增亮**：填充 alpha 提升至 G3 档（浅色 0.72 / 深色 0.18），比未选中邻居明显更「实」；
2. **柔和光晕**：容器外缘发出主题色光晕（alpha 0.25，模糊 20，无扩散、无位移），像光从玻璃后面打上来；
3. **透明叠加层**：内部叠加主题色垂直渐变（alpha 顶部 0.12 → 底部 0.06），给玻璃染上一点「色相」，而非盖住它；
4. **高光描边**：内侧高光描边亮度提升 + 外缘 0.5px 主题色细线（alpha 0.30）。

切换过程 200ms 渐隐渐显，四层同步过渡。未选中态任何一层都不出现。

### 5.3 表格

- **容器**：表格整体是一个 G2 玻璃面板，统一承载模糊；
- **表头**：G3 档参数（比表体更实），底部 0.5px 半透明分隔线；
- **斑马纹**：交替行**仅通过填充透明度区分**（浅色差值 0.15 / 深色差值 0.04），不套模糊、不用不同色相；
- **边框**：全表 0.5px 半透明细线；行分隔线左右内缩 16px（iOS 列表惯例）；
- **行交互**：hover 时该行填充 alpha 小幅提升；选中行走 §5.2 完整高亮；
- **单元格**：无独立背景，只承载内容与留白。

### 5.4 按钮与交互元素

按钮是 G2 级玻璃材质，**hover / pressed 通过透明度与模糊程度的变化表达**，各状态参数差异明确（Spec §4.4 状态矩阵）：

| 状态 | 视觉变化方向 |
| --- | --- |
| 默认 | G2 基准材质 |
| Hover | 模糊 ↑（更磨砂）+ 填充变实 + 描边高光 ↑ —— 玻璃「浮起」 |
| Pressed | 模糊 ↓ + 填充变透 + 缩放 0.98 + 内阴影 —— 玻璃「按下」 |
| Focus | 默认态 + 主题色聚焦环 |
| 禁用 | 模糊 ↓↓ + 填充大幅变透 + 去高光描边 —— 玻璃「褪成幽灵」 |

主操作按钮使用**主题色着色的玻璃**（主题色半透明填充 + 模糊），而非实色；文字保持白色实色。次级/文字按钮沿用无色玻璃。

### 5.5 卡片与面板

- 所有容器类组件（数据卡、图表容器、设置分组、弹层底板）统一 G2 起档；
- 标配三件套：半透明填充 + 双层发丝描边 + 顶部内高光渐变；
- 投影为「环境投影」：低透明度、大模糊、小位移（对齐 iOS 的柔和悬浮感），禁止使用彩色阴影；
- 卡片之间通过留白分组，禁止卡片套卡片（层级最多嵌套一层，内层升一档）。

### 5.6 导航与吸附层

- 吸顶 AppBar、底部导航栏使用 G3：滚动内容从其下方穿过时被实时柔化（iOS 导航栏标准行为）；
- 滚动到顶部静止时，导航栏分隔线隐藏；滚动后 0.5px 分隔线渐显（iOS 惯例）。

## 6. 文字与可读性

- 文字永远实色、不参与玻璃半透明，渲染于所属玻璃层之上；
- 色阶对齐 iOS Label 体系：主文字 / 次级 / 三级 / 禁用四档，深浅模式各一套取值（Spec §5）；
- 全部文字-背景组合 ≥ WCAG AA 4.5:1（大文字 ≥ 3:1），Spec §7 给出逐层级验算值，AC-03 自动化校验；
- 数字（金额等）使用等宽数字字形，禁止给数字加玻璃底衬（数字直接落在卡片上）。

## 7. 圆角、阴影、边框语言

| 语言 | 规范 |
| --- | --- |
| 圆角 | 连续圆角（squircle 近似）；全系统四档：8（小控件）/ 12（图标容器基准比例）/ 16（卡片）/ 20（浮层）；胶囊元素（Toast、标签）用全圆角 |
| 阴影 | 单光源环境投影：黑色，alpha 0.04–0.12 随层级递增；禁彩色阴影、禁多层堆叠阴影 |
| 边框 | 一律 0.5px 发丝线；双层制：外侧深色勾边 + 内侧白色高光；禁止 ≥1px 的实色边框 |

## 8. 动效原则

- 时长：微交互 150ms，状态切换 200ms，浮层进出 250ms；统一 `cubic-bezier(0.4, 0.0, 0.2, 1)`；
- 可动属性仅限：透明度、模糊半径、缩放（0.98–1.0）、位移（≤ 8px）；禁止颜色跳变（颜色必须过渡）；
- 选中态光晕的出现/消失跟随选中切换同步渐变，不做呼吸、脉冲等循环动画；
- 系统「减弱动态效果」开启时：全部过渡降级为 100ms 纯透明度变化（Spec §6）。

## 9. 深色 / 浅色双模式

- 同一套 G1–G5 层级，两套填充/描边/阴影取值（Spec §3 参数表双列给出）；
- 填充色双向统一为 `#FFFFFF` 基色：浅色模式高 alpha 白玻璃、深色模式低 alpha 白玻璃（落在纯黑背景上呈深灰玻璃），保证两模式的玻璃「同源不同浓度」；
- 主题色在深色模式下整体提亮（Spec §2 给出深浅两值），保证光晕与聚焦环在纯黑背景上可见；
- 切换主题时全部 Token 200ms 过渡，禁止闪变。

## 10. 禁用清单（全系统红线）

| # | 禁止项 | 原因 |
| --- | --- | --- |
| 1 | 背景光斑 / 光晕 / 彩色渐变 / Mesh / 噪点 / 网格 / 背景图 | 纯净背景硬约束（§3） |
| 2 | 实色填充的选中态 | 选中必须走毛玻璃高亮（§5.2） |
| 3 | 组件私自定义模糊半径 / 填充 alpha | 参数单源（Spec §2，AC-01 扫描门禁） |
| 4 | 表格行 / 列表项逐个套 `BackdropFilter` | 性能红线（§4.3，AC-06） |
| 5 | 彩色投影、多层堆叠投影 | 阴影语言统一（§7） |
| 6 | ≥1px 实色边框 | 边框一律 0.5px 半透明发丝线（§7） |
| 7 | 文字半透明参与玻璃混色 | 内容永不下沉（§6） |
| 8 | 旧玻璃方案 Token（`ambient` 系列、`glassFill*` 派生等）残留 | 旧系统完全废弃（Spec §8，AC-08） |
