## 1. 总览

- **范围**：主题系统（8 套预制 + 切换接口）、设计 Token 与组件库、15 个 feature 模块 UI 迁移、自定义背景 + 智能遮罩、测试与验收。
- **工时**：18 个工作日（单人全栈），粒度沿用项目惯例 0.5~3 天。
- **排期窗口**：2026-08-10（周一）~ 2026-08-28（周五），按 5 个工作日/周。
- **节奏约定**：始终维持 ≥ 1 个 in_progress 任务；每个波次结束过里程碑评审。

## 2. 波次依赖（DAG）

```
W1 设计系统基础 ──┬──> W2 组件库 ──> W3 页面迁移 ──┐
                 │                                ├──> W5 测试验收
                 └──> W4 背景系统（仅需 Token）───┘
```

W4 与 W2/W3 可并行（依赖仅限 W1 的 Token 层），单人执行时按 W1→W2→W3→W4→W5 串行排期。

## 5. 验收标准（全局）

1. 8 套主题在五个主 Tab 观感完整，文字对比度全部 ≥ WCAG AA（正文 4.5:1）。
2. 背景图五档亮度（极亮/亮/中调/暗/极暗）下账单列表清晰可读；遮罩模式可切换、可手动微调。
3. 组件 Gallery 覆盖 Spec §6 全部组件 × 8 主题；Golden 基线全绿。
4. CI 静态卡点生效：features/ 无裸色值/裸字号新增。
5. 性能指标达成（Spec §8）；旧用户升级无观感跳变（'custom' 兼容路径）。
