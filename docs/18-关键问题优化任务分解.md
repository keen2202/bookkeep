## 1. 总览

- **范围**：UI 图标玻璃拟态重构、背景图热重载与交互层级修复、快速记账退出逻辑完善。
- **工时**：4 个工作日（单人），粒度 0.5~1 天。
- **排期窗口**：2026-08-17 ~ 2026-08-21。
- **状态口径**：`pending` / `in_progress` / `completed` / `blocked`。

## 2. 波次依赖（DAG）

```
W1 图标体系（UI）                W2 背景修复                         W3 快速记账退出
BK-OPT-001 ──> BK-OPT-002      BK-OPT-003 ──> BK-OPT-004           BK-OPT-007
                                   └──> BK-OPT-005                      │
BK-OPT-006（文档/验收） <─────────────┴─────────────┘                  │
BK-OPT-008（回归与 Golden） <──────────────────────────────────────────┘
BK-OPT-009（最终验收）
```

- BK-OPT-003/004/005 为背景修复主链路，可独立于 W1 并行。
- BK-OPT-007 依赖 W3 架构调整，与其他两条主线无硬依赖。
- BK-OPT-008 需等待代码任务完成，用于回归、静态检查与 Golden 重建。
- BK-OPT-009 为最终人工/自动化验收。
